# Chat Logging Policy

This directory stores summarized logs of chat work.

## File naming
- One file per day in KST: `chat_YYYY-MM-DD.md`
- Example: `chat_2026-04-20.md`

## Entry format
Each task should append one block with:
- Timestamp (KST)
- User request summary
- Actions performed
- Outcome and validation status
- Notes/next steps (if any)

## Rule
After finishing each chat task, append an entry to today's log file.
